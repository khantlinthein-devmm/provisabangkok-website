SMART-виза предназначена для высококвалифицированных специалистов, инвесторов, руководителей и основателей стартапов, которые хотят работать и/или инвестировать в одну из следующих отраслей:

- Автомобилестроение нового поколения
- Умная электроника
- Премиальный, медицинский и оздоровительный туризм
- Сельское хозяйство и биотехнологии
- Продукты питания будущего
- Автоматизация и робототехника
- Биотопливо и биохимия
- Цифровая отрасль
- Медицинский хаб
- Альтернативное разрешение споров
- Развитие кадров в науке и технологиях
- Экология и возобновляемая энергетика

## Виды SMART-виз

1. **SMART Visa «T»** — для иностранных специалистов
2. **SMART Visa «I»** — для иностранных инвесторов
3. **SMART Visa «E»** — для иностранных руководителей
4. **SMART Visa «S»** — для иностранных основателей технологических стартапов
5. **SMART Visa «O»** — для членов семьи (супругов и детей) обладателей указанных SMART-виз
